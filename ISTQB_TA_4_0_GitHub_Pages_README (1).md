# ISTQB® CTAL-TA v4.0 – Übungen

Interaktiver, lernzielvollständiger Übungsbogen für **CTAL-TA v4.0**.

## GitHub Pages

Nach dem Push auf `main` veröffentlicht der Workflow die Inhalte aus `site/` automatisch über GitHub Pages.

Erwartete URL:

`https://alexlindnerBABIX.github.io/ISTQB-TA-4.0/`

## Inhalt

- 36 originäre Fragen – jedes Lernziel genau einmal
- 13 prüfungsnahe Grafiken
- Lösung und Begründung je Antwortoption
- **Prof.-Tipps** direkt an jeder Antwort: kurz, leicht, mit etwas trockenem Professorenhumor
- Fortschritt lokal im Browser
- Antwortreihenfolge stabil randomisiert
- Standalone-HTML; keine Laufzeit-Abhängigkeiten

## Bedienung

- Antwort wählen und **Antwort prüfen**
- **Prof.** neben einer Option: Mouseover/Fokus; auf Touch antippen
- Lernzielübersicht, Rücksprung und Ergebnisexport sind integriert

## Struktur

- `site/index.html` – produktive GitHub-Pages-App
- `assets/` – editierbare JPG-Quellen der Grafiken
- `qa/` – Qualitäts- und Grafikprüfungen
- `.github/workflows/pages.yml` – automatische Pages-Bereitstellung

## Hinweis

Der Übungsbogen ist lernzielvollständig, aber keine 1:1-Nachbildung der offiziellen Prüfungsverteilung.
